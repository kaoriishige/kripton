- **ホスティング**: Netlify

- **SEO・AI検索対策**: セマンティックHTML、JSON-LD（Plumber, FAQPage）、OGP、Core Web Vitals最適化

## ディレクトリ構成

- `src/pages/`: 各ページコンポーネント（トップページ、症状別、施工事例、プレビューハブ）
- `src/components/`: 共通UIコンポーネント（ヘッダー、フッター、スマホ追従電話バー、ヒーロー等）
- `src/layouts/`: 共通レイアウト（Layout.astro）
- `src/data/`: 会社情報、修理サービス一覧、対応地域、施工事例のマスターデータ
- `src/styles/`: デザインシステムCSS（global.css）
- `public/`: 静的アセット（robots.txt、キャラクター画像等）
- `docs/`: 移行管理資料（URL台帳、移行監査表、バックアップチェックリスト等）

## 開発・ビルドコマンド

```bash
# 依存関係のインストール
npm install

# 開発サーバー起動（プレビューハブ含む）
npm run dev

# 静的HTMLのビルド
npm run build

# ビルド成果物のローカルプレビュー
npm run preview
```
