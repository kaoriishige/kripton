## 4. 本番切り替え手順（承認受領後）

1. オーナー様からの明示的な「切り替え承認」の確認
2. DNSレコード変更（Webの向け先をNetlifyのロードバランサーまたはCNAMEへ向ける）
3. Netlify管理画面で独自ドメインを設定し、Let's Encrypt SSL証明書を自動プロビジョニング
4. ドメイン疎通確認（HTTP → HTTPSリダイレクト、www統一リダイレクト）
5. Google Search Console / Google Analytics の更新
6. 翌日および1週間後のメール・アクセスログ監査
